# Share uu scout / 分享 uu scout

## Website / 网站

1. In this repository open **Settings → Pages**. Under **Build and deployment**, choose **GitHub Actions** as the source.
2. Open **Actions → Publish uu scout → Run workflow**, choose `main`, and run it. Wait for the deployment to succeed.
3. Share **https://rititititi.github.io/ticketing/** with fans. This URL becomes available after GitHub Pages finishes deploying.

1. 进入本仓库的 **Settings（设置）→ Pages**，在 **Build and deployment** 中将来源选择为 **GitHub Actions**。
2. 进入 **Actions → Publish uu scout → Run workflow**，选择 `main` 并运行，等待部署成功。
3. 将 **https://rititititi.github.io/ticketing/** 分享给其他粉丝。GitHub Pages 部署成功后，此网址即可访问。

Future changes to the site's code or catalog on `main` redeploy automatically. The website is static: no Python server, sign-in, API key, checkout or payment service is required. Visitors can choose English or 简体中文; the choice is remembered on their device. Original screenshots and raw source text remain in their original language.

后续 `main` 分支中的网站代码或目录数据更新会自动重新部署。网站为静态页面，无需 Python 服务器、登录或 API 密钥，也不提供结账或收款服务。访客可选择 English 或简体中文，设备会记住语言偏好。原始截图及原文保持原语言。

## Download / 下载

Download [uu-scout.zip](https://github.com/rititititi/ticketing/raw/refs/heads/main/uu-scout.zip), unzip it, and open `uu-scout/index.html`. Keep `source-images/` beside it. You can share the same ZIP link with others; GitHub's raw HTML link is a download, not the hosted website.

下载 [uu-scout.zip](https://github.com/rititititi/ticketing/raw/refs/heads/main/uu-scout.zip)，解压后打开 `uu-scout/index.html`，并将 `source-images/` 保留在旁边。也可直接分享此 ZIP 下载链接；GitHub 的原始 HTML 链接是文件下载地址，并非网站访问地址。
